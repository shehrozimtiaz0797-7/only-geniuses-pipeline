Only Geniuses Uploader

Only Geniuses is a YouTube Shorts channel that posts a new brain teaser every day: riddles, logic puzzles and number puzzles with a 10-second countdown and the answer at the end.

What this app does

Only Geniuses Uploader is a private tool used only by the owner of the Only Geniuses channel. It makes the quiz videos automatically and uploads them to that one YouTube channel using the YouTube Data API.

It is not offered to the public, and it does not sign in or upload for anyone else.
